Early Preview · Bare Metal · Rust

CDK — Cognitive Distributed Kernel

A capability-first, distributed-ready kernel that boots on real hardware (via QEMU today) with preemptive scheduling, object IPC, network service routing, and evolving multicore runtime support.

View on GitHub Read Docs

Why CDK

Capability Security

Operations are gated through cryptographic capabilities instead of ambient authority.

Intent Scheduling

Tasks carry intent labels (`low_latency`, `batch`, `interactive`) mapped to priorities.

Distributed by Design

Node awareness, message routing patterns, and bridge telemetry are built into the model.

Current Scope

  • x86_64 bare-metal boot flow with `bootloader_api` and serial console
  • Priority scheduler with timer-driven preemption
  • Kernel object model + typed IPC message queues
  • Loopback and external network interfaces with capability-gated access
  • Multicore bring-up scaffolding through AP startup phases

Quick Start

rustup target add x86_64-unknown-none
rustup toolchain install nightly
rustup component add rust-src llvm-tools-preview --toolchain nightly
sudo apt install qemu-system-x86

./run_qemu.sh

After boot, use the cdk> prompt and run help.
